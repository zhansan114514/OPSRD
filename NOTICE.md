# Attribution

OPSRD is an extension of the public OPSD implementation at
<https://github.com/siyan-zhao/OPSD>. This repository keeps the upstream
attribution and identifies the additional role-conditioned distillation,
entropy-selection, divergence, clipping, evaluation, and compatibility code.

The upstream repository does not currently include a license file. This release
therefore makes the research code publicly inspectable and reproducible without
asserting a new license over upstream material. Please preserve this notice and
the upstream attribution when reusing the code.
